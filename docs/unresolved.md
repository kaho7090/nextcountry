# 未解決事項

## マスタ件数 249（CSV）と UI 252 件表示の差

- **状況**: 利用環境で「CSV 249 件」に対し画面が 252 件になる報告がある。
- **VM 上の調査**: 現行コードで `ensure_database()` 後の `countries` は **250 件**（CSV 250 件、または CSV 249 + 補完 `XK`）まで。252 件は再現できていない。
- **想定される要因（コード上）**: `ensure_database` は CSV の UPSERT のみで、CSV から削除された国を DB から削除しないため、過去のより大きいマスタが DB に残存している可能性。
- **対応方針**: 訪問履歴・優先度の無断削除や DB ファイルの削除は行わない。マスタ同期の整理は別タスクで、個人データを保持した差分調査から行う。
